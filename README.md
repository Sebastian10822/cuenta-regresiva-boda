# Cuenta regresiva de boda 💍

Proyecto HTML listo para Vercel.

- Fecha: 11 de octubre de 2026
- Hora: 4:00 p. m.
- Zona horaria: Colombia (UTC-5)
- La cuenta regresiva se calcula con la hora real de cada visita y se actualiza cada segundo.
- La fotografía `boda.jpg` se usa como fondo.
- No requiere React, Node, npm ni base de datos.

## Actualizar en Vercel

Si el proyecto ya existe en Vercel mediante Vercel Drop, vuelve a desplegar esta carpeta/proyecto para crear una nueva implementación con los cambios.
